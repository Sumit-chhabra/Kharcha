Google Sheets Setup
One-time, 5 minutes · your data stays in your Google account
1
Create a Google Sheet
Go to sheets.new — a new blank spreadsheet opens. Name it Kharcha. Keep this tab open.
2
Open Apps Script
In your sheet: click Extensions → Apps Script. A code editor opens. Delete everything already there.
3
Paste the backend code
Copy all the code from the kharcha-apps-script.js file I provided, paste it into the Apps Script editor. Click Save (💾 icon or Ctrl+S).
4
Deploy as Web App
Click Deploy → New deployment → gear icon → Web app.

Set: Execute as: Me
Set: Who has access: Anyone (don't worry — only people with your secret URL can use it)

Click Deploy → Grant permissions when asked → Copy the Web app URL.
5
Paste your URL below
Paste your Apps Script Web App URL here. Kharcha will connect and create your sheets automatically.
